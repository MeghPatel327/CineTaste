2. TABLES AND FIELDS ARCHITECTURE
================================================================================

Create the following 8 tables with the exact field names, field types, and options specified below:

--------------------------------------------------------------------------------
TABLE 1: Users (Target Env: BASEROW_TABLE_USERS)
Purpose: Stores registered users, credential hashes, roles, and preferences. Plaintext passwords MUST NEVER be stored.
--------------------------------------------------------------------------------
- "user_id" (Type: Single line text, Primary / Stable Identifier e.g. "usr_clx...")
- "email" (Type: Email, unique identifier for login)
- "username" (Type: Single line text)
- "password_hash" (Type: Single line text, contains PBKDF2/Argon2 salt+hash string)
- "role" (Type: Single select, Options: "user", "admin", default: "user")
- "avatar_url" (Type: URL)
- "preferred_genres" (Type: Multiple select, Options: "Action", "Adventure", "Animation", "Comedy", "Crime", "Documentary", "Drama", "Family", "Fantasy", "History", "Horror", "Music", "Mystery", "Romance", "Sci-Fi", "Thriller", "War", "Western")
- "is_active" (Type: Boolean, default: true)
- "created_at" (Type: Date or Single line text ISO timestamp)
- "updated_at" (Type: Date or Single line text ISO timestamp)

--------------------------------------------------------------------------------
TABLE 2: Media (Target Env: BASEROW_TABLE_MEDIA)
Purpose: Cached movie and TV series metadata synced from TMDB to eliminate redundant external TMDB calls.
--------------------------------------------------------------------------------
- "tmdb_id" (Type: Single line text, Primary Identifier e.g. "movie-693134" or "tv-94605")
- "title" (Type: Single line text)
- "original_title" (Type: Single line text)
- "media_type" (Type: Single select, Options: "movie", "tv")
- "tagline" (Type: Single line text)
- "overview" (Type: Long text)
- "release_year" (Type: Number, Integer)
- "release_date" (Type: Date)
- "runtime" (Type: Single line text, e.g. "2h 46m")
- "tmdb_rating" (Type: Number, Decimal 1 place, e.g. 8.8)
- "vote_count" (Type: Number, Integer)
- "genres" (Type: Multiple select, Options: "Action", "Adventure", "Animation", "Comedy", "Crime", "Documentary", "Drama", "Family", "Fantasy", "History", "Horror", "Music", "Mystery", "Romance", "Sci-Fi", "Thriller", "War", "Western")
- "poster_url" (Type: URL)
- "backdrop_url" (Type: URL)
- "badge" (Type: Single select, Options: "4K UHD", "IMAX", "HDR10+", "DOLBY VISION")
- "audio_format" (Type: Single select, Options: "Dolby Atmos", "5.1 Surround", "Stereo")
- "directors" (Type: Single line text, comma-separated e.g. "Denis Villeneuve")
- "top_cast" (Type: Single line text, comma-separated e.g. "Timothée Chalamet, Zendaya")
- "cached_at" (Type: Date or Single line text ISO timestamp)

--------------------------------------------------------------------------------
TABLE 3: UserMedia (Target Env: BASEROW_TABLE_USER_MEDIA)
Purpose: Tracks a user's personal relationship to a title (Library status, Queue, Ratings, Favorites, Exclusions).
--------------------------------------------------------------------------------
- "record_id" (Type: Single line text, Primary Identifier e.g. "um_usr1_tmdb693134")
- "user_id" (Type: Single line text, foreign key reference to Users)
- "tmdb_id" (Type: Single line text, foreign key reference to Media)
- "library_status" (Type: Single select, Options: "watching", "completed", "plan_to_watch", "dropped", "none", default: "none")
- "is_in_queue" (Type: Boolean, default: false)
- "is_favorite" (Type: Boolean, default: false)
- "user_rating" (Type: Number, Decimal 1 place or Integer, 1 to 10 scale, empty if unrated)
- "watch_progress" (Type: Number, Integer, percentage 0 to 100 for Continue Watching)
- "is_excluded" (Type: Boolean, default: false, hides title from recommendations)
- "notes" (Type: Long text)
- "completed_at" (Type: Date or Single line text ISO timestamp)
- "updated_at" (Type: Date or Single line text ISO timestamp)

--------------------------------------------------------------------------------
TABLE 4: WatchProviders (Target Env: BASEROW_TABLE_WATCH_PROVIDERS)
Purpose: Administrator-managed directory of external streaming, rent, buy, or community watch services. No hardcoded site URLs in frontend code.
--------------------------------------------------------------------------------
- "provider_id" (Type: Single line text, Primary Identifier e.g. "prov_apple_tv", "prov_external_site1")
- "provider_name" (Type: Single line text, e.g. "Apple TV", "Prime Video", "Flixtor Mirror")
- "provider_type" (Type: Single select, Options: "subscription", "rent_buy", "free_ad_supported", "external_catalog")
- "base_url" (Type: URL)
- "icon_url" (Type: URL)
- "badge_label" (Type: Single line text, e.g. "Official 4K", "Community Mirror")
- "is_active" (Type: Boolean, default: true)
- "display_order" (Type: Number, Integer)

--------------------------------------------------------------------------------
TABLE 5: MediaWatchLinks (Target Env: BASEROW_TABLE_MEDIA_WATCH_LINKS)
Purpose: Concrete per-title external watch links. Enables users to discover verified watch options without CineTaste hosting or playing pirated/embedded media.
--------------------------------------------------------------------------------
- "link_id" (Type: Single line text, Primary Identifier e.g. "link_dune2_site1")
- "tmdb_id" (Type: Single line text, reference to Media)
- "provider_id" (Type: Single line text, reference to WatchProviders)
- "direct_url" (Type: URL, destination webpage for the specific movie/series)
- "quality_label" (Type: Single select, Options: "4K UHD", "1080p FHD", "720p HD", "SD")
- "language_audio" (Type: Single line text, e.g. "English", "Original Audio")
- "is_verified" (Type: Boolean, default: true)
- "click_count" (Type: Number, Integer, default: 0)
- "created_at" (Type: Date or Single line text ISO timestamp)

--------------------------------------------------------------------------------
TABLE 6: Recommendations (Target Env: BASEROW_TABLE_RECOMMENDATIONS)
Purpose: Caches generated recommendation batches per user from Gemini Web2API or heuristic engine, avoiding repetitive generation costs.
--------------------------------------------------------------------------------
- "recommendation_id" (Type: Single line text, Primary Identifier e.g. "rec_usr1_202610")
- "user_id" (Type: Single line text, reference to Users)
- "source_engine" (Type: Single select, Options: "gemini_local", "gemini_prod", "algorithmic_fallback")
- "candidate_tmdb_ids" (Type: Long text, JSON string array of recommended tmdb IDs)
- "match_reasons" (Type: Long text, JSON object mapping tmdb_id -> explanation text)
- "taste_focus" (Type: Single line text, e.g. "Dystopian Cyberpunk & Cerebral Sci-Fi")
- "created_at" (Type: Date or Single line text ISO timestamp)
- "expires_at" (Type: Date or Single line text ISO timestamp)

--------------------------------------------------------------------------------
TABLE 7: TasteProfiles (Target Env: BASEROW_TABLE_TASTE_PROFILES)
Purpose: Computes user Taste DNA vector based on actual watching history and ratings.
--------------------------------------------------------------------------------
- "profile_id" (Type: Single line text, Primary Identifier e.g. "taste_usr1")
- "user_id" (Type: Single line text, unique reference to Users)
- "primary_genres" (Type: Multiple select, Options: same as Users table)
- "affinity_scores" (Type: Long text, JSON object e.g. {"Sci-Fi":0.92,"Neo-Noir":0.85})
- "director_affinities" (Type: Single line text, comma-separated e.g. "Denis Villeneuve, Christopher Nolan")
- "total_completed" (Type: Number, Integer)
- "total_hours_watched" (Type: Number, Integer)
- "average_rating" (Type: Number, Decimal 1 place)
- "last_recalculated" (Type: Date or Single line text ISO timestamp)

--------------------------------------------------------------------------------
TABLE 8: RecommendationFeedback (Target Env: BASEROW_TABLE_FEEDBACK)
Purpose: Logs user feedback on recommendations (thumbs up, thumbs down, dismiss) to tune the diversity engine.
--------------------------------------------------------------------------------
- "feedback_id" (Type: Single line text, Primary Identifier e.g. "fb_usr1_tmdb123")
- "user_id" (Type: Single line text)
- "tmdb_id" (Type: Single line text)
- "action" (Type: Single select, Options: "thumbs_up", "thumbs_down", "dismiss", "added_to_queue")
- "created_at" (Type: Date or Single line text ISO timestamp)
