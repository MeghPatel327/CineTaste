# Development Rules

1. Always follow PRD before coding.
2. Keep modules independent.
3. No business logic inside UI components.
4. API routes only orchestrate services.
5. Use TypeScript everywhere.
6. Never store plain-text passwords.
7. Validate all user input.
8. Reuse components before creating new ones.
9. Keep functions small and readable.
10. Avoid duplicate code.
11. Recommendation engine must remain deterministic (no AI).
12. TMDB is the only metadata provider in V1.
13. Never modify user data from admin except block/delete/role.
14. Every feature should be production-ready.
15. Prefer clarity over cleverness.
16. Document major architectural decisions.
17. Keep prompts for IDE agents small and focused.
