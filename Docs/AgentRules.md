# Agent Rules

## Mandatory
- Read PRD before coding.
- Follow Architecture.md.
- Never change database schema without updating Schema.md.
- Never bypass service layer.
- Never place business logic inside React components.
- Never use any in TypeScript.
- Keep functions under ~50 lines where practical.
- Keep components focused.
- Reuse utilities.
- Update Tracker.md after feature completion.
- Ask for clarification instead of guessing business rules.
