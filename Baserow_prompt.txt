# CineTaste — Baserow Database Setup Prompt
# Copy this entire prompt into Baserow AI or use as a manual setup guide.
# Every field listed here is REQUIRED unless marked [optional].

---

## Overview

CineTaste uses 6 Baserow tables (7 if using the optional dedicated Games table):

| Table | Env Var | Purpose |
|---|---|---|
| users | BASEROW_USERS_TABLE_ID | Authentication & user accounts |
| movies | BASEROW_MOVIES_TABLE_ID | Movie, Series, Anime library items |
| pirate_sites | BASEROW_PIRATES_TABLE_ID | Streaming/download links for movies/series/anime |
| recommendation_profile | BASEROW_RECOMMENDATION_PROFILE_TABLE_ID | AI taste profiles per user |
| recommendation_sets | BASEROW_RECOMMENDATION_SETS_TABLE_ID | Cached AI-generated recommendations |
| games | BASEROW_GAMES_TABLE_ID | Dedicated game library (separate from movies) |
| game_pirate_sites | BASEROW_GAME_PIRATES_TABLE_ID | Streaming/download links for games |

---

## IMPORTANT: Field Type Rules

- Use ONLY plain text, long text, number, boolean, date, and URL field types.
- NEVER use single_select or multi_select — the app stores genres, platforms, and statuses as plain text strings.
- Do NOT add foreign key / link-to-table fields between tables.
- Status values are plain text strings — the app validates them.

---

## Table 1: users

**Env var:** `BASEROW_USERS_TABLE_ID`

| Field | Type | Notes |
|---|---|---|
| username | Text | Unique login name |
| password_hash | Long Text | bcrypt hash |
| role | Text | "user" or "admin" |
| blocked | Boolean | Default false |
| created_at | Text | ISO-8601 string |
| last_login | Text | ISO-8601 string, [optional] |

---

## Table 2: movies

**Env var:** `BASEROW_MOVIES_TABLE_ID`

Stores Movies, Series, and Anime only. Games are in a separate table.

| Field | Type | Notes |
|---|---|---|
| username | Text | Owner's login name |
| movie_name | Text | Title of the content |
| type | Text | "movie", "series" |
| status | Text | "pending", "watching", "on_hold", "completed", "dropped" |
| rating | Number | 0–10 |
| personal_review | Long Text | User's notes/review |
| watch_order_rank | Number | Queue position, [optional] |
| watch_link | URL | Direct watch/stream link, [optional] |
| tmdb_id | Number | Canonical TMDB ID |
| genres | Long Text | JSON array string e.g. '["Action","Drama"]' |
| release_year | Number | e.g. 2024 |
| runtime | Number | Minutes for movies; episodes for series |
| language | Text | ISO language code e.g. "en", "ja" |
| poster_url | URL | Poster image URL |
| overview | Long Text | TMDB synopsis |
| created_at | Text | ISO-8601 string |
| updated_at | Text | ISO-8601 string |

**Status meanings for movies table:**
- `pending` = Added to watchlist, not started
- `watching` = Currently watching (also used as "Playing" in legacy game code — but new games use their own table now)
- `on_hold` = Paused / waiting for new episodes
- `completed` = Finished watching
- `dropped` = Abandoned

---

## Table 3: pirate_sites (for movies/series/anime only)

**Env var:** `BASEROW_PIRATES_TABLE_ID`

Streaming and download site links shown in movie/series/anime detail cards.

| Field | Type | Notes |
|---|---|---|
| name | Text | Display name e.g. "1337x", "YTS" |
| search_url | URL | Template URL with `{q}` placeholder e.g. `https://1337x.to/search/{q}/1/` |
| enabled | Boolean | Only enabled sites are shown to users |

---

## Table 4: recommendation_profile

**Env var:** `BASEROW_RECOMMENDATION_PROFILE_TABLE_ID`

One row per user. Stores AI-generated taste DNA.

| Field | Type | Notes |
|---|---|---|
| username | Text | Owner |
| strong_likes | Long Text | JSON: genres the user loves |
| strong_dislikes | Long Text | JSON: genres the user avoids |
| unclassified | Long Text | JSON: neutral genres |
| summary | Long Text | Freeform AI taste summary paragraph |
| generated_at | Text | ISO-8601 string |

---

## Table 5: recommendation_sets

**Env var:** `BASEROW_RECOMMENDATION_SETS_TABLE_ID`

Cached recommendation results per user per category.

| Field | Type | Notes |
|---|---|---|
| username | Text | Owner |
| category | Text | "movies", "series", "anime" |
| recommendations | Long Text | JSON array of recommendation objects |
| generated_at | Text | ISO-8601 string |
| expires_at | Text | ISO-8601 string |

---

## Table 6: games

**Env var:** `BASEROW_GAMES_TABLE_ID`

**REQUIRED** — this is a fully separate table from movies. Do NOT reuse the movies table for games.

| Field | Type | Notes |
|---|---|---|
| username | Text | Owner's login name |
| game_name | Text | Title of the game |
| status | Text | "playing", "completed", "pending", "on_hold", "dropped" |
| rating | Number | 0–10 |
| personal_review | Long Text | User's notes/review |
| watch_order_rank | Number | Backlog queue position, [optional] |
| rawg_id | Number | Canonical RAWG game ID |
| genres | Long Text | JSON array string e.g. '["RPG","Adventure"]' |
| platforms | Long Text | JSON array string e.g. '["PC","PS5"]' |
| release_year | Number | e.g. 2022 |
| playtime_hours | Number | Hours played |
| cover_url | URL | RAWG cover art URL |
| backdrop_url | URL | RAWG screenshot/artwork URL, [optional] |
| summary | Long Text | RAWG game synopsis |
| created_at | Text | ISO-8601 string |
| updated_at | Text | ISO-8601 string |

**Status meanings for games table:**
- `playing` = Currently playing (stored natively — no translation to "watching")
- `completed` = Finished
- `pending` = Backlog / plan to play
- `on_hold` = Paused
- `dropped` = Abandoned

**Key difference from movies table:**
- Uses `rawg_id` (not `tmdb_id`) as the canonical content identifier
- Uses `platforms` (JSON array) instead of `language`
- Uses `playtime_hours` (not `runtime`)
- Status `"playing"` is stored directly (movies use `"watching"` for the same concept)
- Completely separate table — queries never mix movies and games

---

## Table 7: game_pirate_sites

**Env var:** `BASEROW_GAME_PIRATES_TABLE_ID`

Streaming and download site links for games. Completely separate from the movies pirate_sites table.

| Field | Type | Notes |
|---|---|---|
| name | Text | Display name e.g. "GOG", "Epic Games Store", "GameJolt" |
| search_url | URL | Template with `{q}` placeholder e.g. `https://www.gog.com/en/games?search={q}` |
| enabled | Boolean | Only enabled sites shown in game detail cards |

## Environment Variables

Add all of these to your `.env.local` (development) and Vercel environment variables (production):

```
# Baserow
BASEROW_API_URL=https://api.baserow.io
BASEROW_DATABASE_ID=<your-database-id>
BASEROW_API_TOKEN=<your-api-token>
BASEROW_USERS_TABLE_ID=<table-id>
BASEROW_MOVIES_TABLE_ID=<table-id>
BASEROW_PIRATES_TABLE_ID=<table-id>
BASEROW_RECOMMENDATION_PROFILE_TABLE_ID=<table-id>
BASEROW_RECOMMENDATION_SETS_TABLE_ID=<table-id>
BASEROW_GAMES_TABLE_ID=<table-id>
BASEROW_GAME_PIRATES_TABLE_ID=<table-id>

# TMDB (for movies/series/anime)
TMDB_API_KEY=<your-tmdb-api-key>

# RAWG (for games)
# Get a free API key at https://rawg.io/apidocs
# Leave blank to use curated game fallback data
RAWG_API_KEY=

# Gemini AI
GEMINI_API_KEY=anything
GEMINI_API_BASE_URL=https://gemini-web2api-clone.vercel.app/v1
GEMINI_MODEL=gemini-3.7-flash

# Recommendation cache lifetime
RECOMMENDATION_FRESHNESS_HOURS=72

# App
NEXT_PUBLIC_APP_URL=http://localhost:3000
AUTH_SECRET=change_me_to_a_random_secret
```

---

## Admin Panel — Managing Sites

After setup, go to `/admin` in the app to:
- Add/edit/delete movie/series/anime streaming sites (`pirate_sites` table)
- Add/edit/delete game streaming/download sites (`game_pirate_sites` table) via `/api/admin/game-pirate-sites`

Both admin endpoints require `role = "admin"` on the user account.

---

## Notes

1. All `created_at` / `updated_at` / `generated_at` fields are ISO-8601 strings like `2024-01-15T10:30:00.000Z` — set them from the app, not Baserow formulas.
2. The `genres` and `platforms` fields hold JSON arrays as plain text — always store them as valid JSON strings.
3. If `BASEROW_GAMES_TABLE_ID` is not set the app throws a configuration error (no silent fallback to movies table).
4. If `BASEROW_GAME_PIRATES_TABLE_ID` is not set the game detail card shows no download/streaming links (graceful degradation).
